# Candidate Feature List

## 101 Workflow and Onboarding
- One-click `New Project` with sensible defaults.
- Auto-create first default scene, first default shot, and first default panel.
- Auto-focus paint area after project creation so user can draw immediately.
- In-app first-run checklist and guided hints.
- Getting Started documentation with screenshots and a 5-minute quickstart.

## Project Model Evolution
- Add optional **Production Container** as a parent of multiple projects.
- Production-level shared settings:
  - resolution presets
  - frame rate defaults
  - naming conventions
  - export defaults
  - shared references/assets
- Keep project-level mode available for solo/lightweight workflows.
- Add migration path from standalone project to production-linked project.

## Storyboard Authoring and UX
- Improve layer ergonomics and defaults for first draw.
- Standardize panel/shot naming and timeline visibility behavior.
- Improve timeline first-use states (clear defaults, no empty/confusing controls).

## Cloud and Sync Direction
- Project sync to cloud database with revisioning.
- Storyboard cloud endpoint for scenes/shots/panels/layers.
- Background upload queue and retry logic.
- Conflict handling strategy for multi-user edits.

## Platform and Delivery
- Cross-platform parity checks: macOS, Windows, Linux.
- Startup diagnostics and first-run health checks.
- Better crash/recovery and autosave defaults.
